# Minigame 1
## Devlog
In order to make the chest minecart, you need a both a regular minecart and a chest. To make a chest, you need wood which can acquired by breaking a tree. 
But those will give you wood logs. You will need to make those into wood planks with a crafting table then you can make a chest. Now to make a minecart, you 
need iron. To get iron, you will need to mine some but when you do, you will need to smelt it before to be able to use it, then you will be able to craft a minecart. 
Once all those steps are completed, you can finally craft the chest minecart.

For this metaphor, the process of getting the original items + the items itself such as the wood and iron are the components because these make up the GameObjects, 
which in this case would be the chest and the minecart. So that would make the chest minecart the scene itself because the GameObjects make up that scene. 

All the items (in both the metaphor and in Unity) directly affect one another because they make up the ending piece, which in these cases would be the chest minecart 
and the scene: Components --> GameObjects --> Scene ; Iron & Wood --> Minecart & Chest --> Chest Minecart.

One cannot exist without the other, or at least thats the way I see it as of right now.
